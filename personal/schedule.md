# 🗓️ 일정 관리

> 🔔 **이 문서는 세션 시작 시 확인 대상이다.** 아래 알림 규칙에 따라 사용자가 묻지 않아도 먼저 알린다.
> 🚫 **사용자가 "빼줘"·"완료" 라고 할 때까지 계속 알린다.** 임의로 중단하지 않는다.

## 📐 관리 원칙

### 그룹핑
- **본문은 프로젝트/태스크별로 묶는다.** 그룹 안에서는 긴급도순(🔴 → 🟠 → 🟡 → ⚪).
- 귀속처가 없는 건은 **`📥 미정`** 그룹에 둔다. 나중에 배정하며, [`projects/etc/`](../projects/etc/INDEX.md) 인박스와 같은 원리다.
- **세션 시작 알림은 그룹이 아니라 긴급도순**으로 낸다(아래 요약표 기준).

### 날짜
| 필드 | 의미 |
|---|---|
| **등록일** | 이 일정을 **여기 추가한 날** |
| **기준일** | 일이 **처음 발생·요청된 날** (외부 요청일·만료일 등). 없으면 등록일과 동일 |
| **기한** | 마감 일시. 없으면 `ASAP` |

**경과는 두 축으로 본다.**

| 축 | 계산 | 의미 |
|---|---|---|
| **요청 후 N일** | 오늘 − 기준일 | **외부 압박** — 상대방이 기다린 기간 |
| **등록 후 N일** | 오늘 − 등록일 | **내부 지연** — 알고도 미룬 기간 |

> ⚠️ **경과일수는 이 문서에 숫자로 적지 않는다.** 날짜만 저장하고 **표시 시점에 계산**한다.

## 🔔 알림 규칙

| 상태 | 기준 | 알림 방식 |
|---|---|---|
| 🔴 **지연** | 기한 초과 · ASAP인데 방치 | **매 세션 최상단**, 양쪽 경과일 함께 |
| 🟠 **임박** | D-1 ~ D-day | **매 세션 최상단** |
| 🟡 **근접** | D-3 ~ D-2 | 응답 중 강조 |
| ⚪ **예정** | D-7 ~ D-4 | 한 줄 안내 |
| 🔁 **반복** | 기한 없이 완주까지 반복 | **긴급도 표에 넣지 않는다.** 하단 `🔁 상시 반복` 절에 **진척률**로 표시(지연 계산 안 함) |
| — | D-8 이상 | 요청 시에만 |

**표시 형식**
```
🔴 [SMS Agent 전환] S-002 벤더 회신 — 요청 후 10일 / 등록 후 0일
   → 전환 가능 일정 + 네트워크 환경(내부망) 회신
```
- **태스크명을 앞에 붙인다** — 어느 일의 일정인지 즉시 알 수 있게.
- **등록 후 경과가 늘어나는데 진척이 없으면** 그 사실을 함께 지적한다.
- 알림은 **간결하게** — 태스크 · 제목 · 양쪽 경과 · 다음 행동 1줄.

### 🔒 미배정 알림 (상시 · 해제 불가)

> 🚫 **일정을 표시할 때마다 맨 아래에 아래 두 가지 미배정 현황을 무조건 붙인다. 해제·생략 대상이 아니다.**

| 대상 | 조건 | 표시 |
|---|---|---|
| **일정 `📥 미정` 그룹** | 1건 이상 | 건수 + 목록 |
| **[`projects/etc/`](../projects/etc/INDEX.md) 대기 목록** | 1건 이상 | 건수 + 문서명 + 배정 후보 |

- **"빼줘"·"완료" 로 끌 수 없다.** 배정이 끝나 항목이 0건이 되면 자연히 사라진다.
- 0건이면 표시하지 않는다(노이즈 방지).
- 배정을 재촉하는 것이 목적이므로 **등록 후 경과일**을 함께 보여준다.
