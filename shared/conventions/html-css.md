# 🎨 HTML / CSS 컨벤션 (초안)

## HTML
- 시맨틱 태그 사용(`header/nav/main/section/footer`)
- 들여쓰기 **탭(Tab)** (스페이스 금지) ✅ 확정, 소문자 태그/속성
- 속성값 큰따옴표, 이미지 `alt` 필수
- 접근성: label-for, 버튼/링크 용도 구분, aria 필요 시
- 인라인 스타일/스크립트 지양(외부 분리)

## CSS
- 클래스 네이밍 방식 통일: **BEM 권장**(`block__element--modifier`) *(← 확정 필요)*
- id 셀렉터로 스타일링 지양(재사용성)
- 색상/치수/폰트는 변수(`:root` 커스텀 프로퍼티)로
- 반응형: 모바일 우선 미디어쿼리 (단, 본 조직 레거시는 PC/모바일 뷰 분리 방식 존재)
- `!important` 최소화

## JSP 뷰 (레거시)
- 공통 레이아웃은 SiteMesh 데코레이터 사용
- taglib(JSTL) 사용, 스크립틀릿(`<% %>`) 신규 작성 지양
- Jakarta 전환 프로젝트는 taglib URI `jakarta.tags.*`

## 금지/주의
- 사용자 입력 출력 시 XSS 이스케이프(`c:out`/서버 필터)
- 인라인 이벤트 핸들러(onclick=) 지양
