# 🟨 JavaScript 컨벤션 (초안)

## 포맷
- 들여쓰기: **탭(Tab) 사용** (스페이스 금지) ✅ 확정
- 세미콜론: 사용
- 문자열: 작은따옴표 또는 템플릿 리터럴 일관
- 한 줄 최대: **200자** ✅ 확정 / 개행 **LF** ✅ 확정

## 문법
- `var` 금지 → `const` 우선, 재할당 시 `let`
- 화살표 함수, 구조분해, 스프레드 활용
- `===`/`!==` (형변환 비교 `==` 금지)
- async/await 우선(콜백/then 남용 지양)

## 네이밍
- 변수/함수 `camelCase`, 클래스/컴포넌트 `PascalCase`, 상수 `UPPER_SNAKE_CASE`

## DOM/jQuery (레거시 JSP 페이지)
- 기존 페이지가 jQuery 기반이면 주변 코드 스타일 따름
- 이벤트 위임, 셀렉터 캐싱
- XSS 방지: 사용자 입력 innerHTML 직접 삽입 금지(텍스트/이스케이프)

## 금지/주의
- `console.log` 운영 코드에 잔존 금지
- 전역 변수 오염 금지(모듈/즉시실행/네임스페이스)
- 하드코딩 URL/키 금지
