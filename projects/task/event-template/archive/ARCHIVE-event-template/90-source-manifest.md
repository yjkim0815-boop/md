## 3. 🔴 자료 이용 시 주의사항

| # | 주의 | 상세 |
|---|------|------|
| 1 | **파일명-내용 불일치** | `02_이벤트 Rule Based EVENT_PROC_BTN 테이블.txt` 의 내용이 **`EVENT_PROC_RULE` DDL로 잘못 채워져 있음**. BTN 컬럼 구성은 **데이터 샘플 헤더로만** 확인 가능 → [31](./31-ddl-event-proc.md#2-event_proc_btn) |
| 2 | **인코딩** | 데이터 샘플 `.txt` 는 **CP949**. UTF-8로 읽으면 한글 깨짐. 변환: `iconv -f CP949 -t UTF-8 <파일>` |
| 3 | **PDF 렌더링 잘림** | 개발DOC PDF의 SQL 코드블록은 **우측이 잘림**. 완전한 DDL은 `이벤트 마크업 DB스키마/*.txt` 로 교차 확인 |
| 4 | **미작성 표** | 착수보고 "6. 이벤트 템플릿(예상) — 위메프 템플릿 기능 분석 List" 는 **헤더만 있고 내용 공백**(착수 시점 미작성) |
| 5 | **md 아카이브 padding** | v1~v10 md는 **동일 챕터가 수십 회 반복**되는 구조(예: v1의 "Chapter 7 - 프로젝트 1차"가 340행 간격 반복). grep 시 중복 히트 다수 → **본 번들의 큐레이션본 사용 권장** |
| 6 | **대용량** | `EV_EN_*` 데이터 80MB/20MB — 열지 말고 필요 시 `head` 로만 확인 |
