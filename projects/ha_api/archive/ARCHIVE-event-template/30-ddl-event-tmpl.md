# 🗄️ `EVENT_TMPL_*` DDL 전문

> **기준**: v10(20260706) 확정본 + 2차 최종 정본의 최신 변경 반영. 스키마 **`SPCADMIN`**.
> **DDL 작성 기준**: 스키마 prefix 미사용 · `CREATE TABLE` 내부 PK 미사용 · `ALTER TABLE`로 PK 분리 · 테이블당 코드블록 1개 · COMMENT 포함.

## 요약표

| 테이블 | PK | 역할 |
|--------|----|------|
| [`EVENT_TMPL_RULE`](#1-event_tmpl_rule) | `RULE_ID` | Rule 마스터. `RULE_TYPE_NM`은 표기용 유형명 |
| [`EVENT_TMPL_BTN`](#2-event_tmpl_btn) | `EVENT_SEQ`,`BTN_ID` | 버튼/트리거 마스터. `START_DT`/`END_DT` DATE 통합 |
| [`EVENT_TMPL_RULE_META`](#3-event_tmpl_rule_meta) | `EVENT_SEQ`,`BTN_ID`,`RULE_ID` | Rule 실행 옵션 JSON |
| [`EVENT_TMPL_FORM`](#4-event_tmpl_form) | `FORM_SEQ` | 프로모션폼 마스터. `FORM_TYPE_NM`·`PREVIEW_IMG_URL` 추가 |
| [`EVENT_TMPL_BRIDGE`](#5-event_tmpl_bridge) | `EVENT_SEQ` | 이벤트↔프로모션폼 연결. `PROMOTION_YN` |
| [`EVENT_TMPL_FORM_HIST`](#6-event_tmpl_form_hist) | `EVENT_SEQ`,`FORM_SEQ` | 프로모션폼 HTML **임시 저장**(⚠️ 이력 아님) |
| [`EVENT_TMPL_CONTENTS`](#7-event_tmpl_contents) | `EVENT_SEQ`,`CONTENTS_TYPE` | 이벤트 마크업 HTML/CSS/JS |
| [`EVENT_TMPL_CONTENTS_HIST`](#8-event_tmpl_contents_hist) | idx | 발행 이력(PROFILE별) |
| [`EVENT_TMPL_ASSETS`](#9-event_tmpl_assets) | `EVENT_SEQ`,`ASSET_FILE_NM` | 리소스(이미지) |
| [`EVENT_TMPL_TESTER`](#10-event_tmpl_tester) | `MBR_NO` | 테스터 |
| [`EVENT_TMPL_TESTER_SEQ`](#11-event_tmpl_tester_seq) | `MBR_NO`,`EVENT_SEQ` | 테스터↔이벤트 매핑 |

### 📌 `EVENT_CHNL` 채널 코드
| 코드 | 채널 |
|------|------|
| `OMBA` | 해피앱 |
| `OHOD` | 해피오더앱 |
| `OSCO` | 해피마켓 |
| `HAPC` | 홈페이지-PC |
| `HAMO` | 홈페이지-모바일 |

> ⚠️ **`EVENT_CHNL` 컬럼은 있으나 PK는 `EVENT_SEQ` 단일** → 이벤트당 1폼만 연결 가능. 채널별 복수 폼이 필요해지면 PK를 `EVENT_SEQ + EVENT_CHNL` 로 재검토해야 한다(→ [71](./71-risks-followups.md)).
