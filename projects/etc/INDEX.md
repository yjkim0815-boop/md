# 📥 etc — 미분류 인박스

> ⚠️ **여기는 최종 보관처가 아니라 "대기실"이다.** 등록 시점에 귀속처를 고민하지 않고 일단 기록하고, **나중에 배정**한다.
> 🚫 **"프로젝트 목록" 표에 표시하지 않는다** (태스크도 프로젝트도 아님).

## 운영 규칙 (2026-08-03 확정)

### 무엇을 넣나
- 프로젝트·태스크 어디에도 명확히 속하지 않는 작업 이력
- 귀속처가 **애매한** 건 → 고민하지 말고 여기에 먼저 기록
- 여러 프로젝트에 걸쳐 있으나 아직 과업으로 묶이지 않은 건

### 무엇을 넣지 않나
- 귀속처가 **분명한** 건 → 해당 프로젝트/태스크에 바로 기록
- 전 프로젝트 공통 규칙 → `shared/`
- 개인 성향·동향 → `personal/`

### 파일 명명
KB 네이밍 규칙을 그대로 따른다.
```
WORKLOG-<YYYYMMDD>-<주제>.md
MEETING-<YYYYMMDD>-<주제>.md
```

### 배정 절차
사용자가 **"etc 내역 보여줘"** 라고 하면 아래 대기 목록을 제시한다.
사용자가 귀속처를 지정하면:
1. `git mv` 로 해당 프로젝트/태스크 폴더로 이동 (**이력 보존**)
2. 상대경로 링크 전부 갱신 후 **링크 검증**
3. 대상 `INDEX.md` 문서목록에 등록
4. 아래 **대기 목록에서 제거하고 배정 이력에 추가**

---

> 🔒 **[해제 불가] 대기 목록에 항목이 1건 이상 있으면, [일정](../../personal/schedule.md) 을 표시할 때마다 맨 아래에 자동으로 함께 노출된다.** 사용자가 끌 수 없으며, **배정이 끝나 0건이 되어야 사라진다.** 방치 방지 장치다.
