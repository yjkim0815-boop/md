# 🤖 개인 AI 활용 (ai)

## 목적과 경계

- Codex·Claude 등 AI 하네스, 공유 컨텍스트 구조, macOS 로컬 모델 설치·운영, 관련 자동화를 관리한다.
- `projects/`는 해피포인트 등 업무 서비스 개발 저장소만 둔다. 이 폴더는 업무 프로젝트가 아닌 개인 AI 활용 영역이다.
- 실제 공유 컨텍스트·원본 자료는 `AI Context`에 둘 수 있으며, 이 문서 영역에는 구조·결정·검증 결과·원본 위치만 기록한다.
- API 키, 토큰, 비밀번호, 모델 가중치, 대화 원문, 개인정보는 기록하지 않는다.

## 참조 방식 — 12시간 수동 컨텍스트 모드

> 이 `ai/` 영역은 **매 세션 자동 주입하지 않는다.**

- 사용자가 **`ai 컨텍스트 연결해`** 라고 지시하면 현재 대화에서 12시간 동안 AI 컨텍스트 모드를 활성화한다.
- 활성 기간에는 이 README와 주제에 직접 관련된 `ai/` 문서를 참조하고, 확정된 구조·설정·검증 결과를 기록한다. 실제 설치·구성·파일 변경은 별도의 명시적 실행 지시가 필요하다.
- 만료 시에는 더 이상 `ai/`를 자동 참조하거나 기록하지 않는다. 다시 필요하면 같은 명령으로 새 12시간을 시작한다.
- 만료 시점에는 Codex 대화 알림 자동화가 사용 가능하면 알림을 예약하고, 다음 대화 응답에서도 만료 사실을 반드시 알린다. Claude Code의 독립 모바일 푸시는 별도 외부 알림 연동이 있어야 보장된다. 새 세션은 기본적으로 비활성 상태로 시작한다.
- AI 관련 단순 질문은 모드를 시작하지 않는다. 사용자가 직접 `ai/` 기록을 지시한 경우에만 해당 작업을 수행한다.

## 다른 프로젝트와 공통인 활성화 규칙

- 자동 주입은 SessionStart 훅의 **사용자 관리 화이트리스트**에 있는 항목만 대상이다. 이 목록은 사용자의 명시적 지시 없이 변경하지 않는다.
- 화이트리스트 밖 프로젝트·아카이브·공통 주제는 **`<프로젝트 또는 주제> 컨텍스트 연결해`** 명령으로 12시간 동안만 수동 활성화한다.
- 예: `이벤트 템플릿 컨텍스트 연결해` → `ha_api`의 이벤트 템플릿 아카이브를 정본으로, `ha_admin`의 관련 포인터를 함께 참조한다.
- 수동 활성화는 현재 대화 단위이며, 동시에 하나의 수동 컨텍스트만 활성화한다. 새 연결 명령은 기존 수동 컨텍스트를 교체한다.

## Codex·Claude Code 공통 규칙 처리

- 사용자가 공통 규칙 적용을 요청하면 Codex·Claude Code 양쪽 적용 가능성을 먼저 검토한다.
- 동일 적용이 가능하면 두 하네스의 전역 지침·공유 훅·설정을 함께 반영하고 검증한다.
- 하네스별 기능 차이(예: 독립 모바일 푸시)나 설정 형식 차이로 예외가 생기면, 예외·영향·대안을 사용자에게 알린다. 한쪽만 적용된 상태를 공통 적용 완료라고 하지 않는다.

## 단계적 구성 계획

1. **기반 확정** — 이 README에 역할·경계·12시간 수동 연결 조건을 유지한다.
2. **자산 인벤토리** — 실제 사용 중인 하네스·모델·연동이 생길 때 `inventory/`에 용도·상태·원본 경로를 기록한다.
3. **운영 설계** — 컨텍스트 읽기 순서와 하네스별 권한이 확정되면 `architecture.md`, `workflows.md`를 만든다.
4. **결정과 이력** — 되돌리기 어려운 선택은 `decisions/ADR-*.md`, 실제 설치·설정·검증은 `worklog/`에 남긴다.
5. **보안 점검** — 로컬 모델·연동 도입 시 데이터 반출 범위, 시크릿 분리, 자동 실행 권한을 별도로 점검한다.

## 예정 구조

```text
ai/
├─ README.md                 # 이 문서: 범위·선택적 참조·진입점
├─ architecture.md           # 확정 후: 컨텍스트/하네스 구조
├─ workflows.md              # 확정 후: 조사·개발·검증 흐름
├─ inventory/                # 실제 자산이 생긴 뒤 생성
├─ decisions/                # 구조적 결정(ADR)
└─ worklog/                  # 설치·설정·검증 이력
```
